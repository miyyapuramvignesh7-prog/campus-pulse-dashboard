# Campus Pulse — College Student Dashboard

A responsive student dashboard concept based on Group 2, Question 3 in the supplied PDF.

## Features
- Student profile and semester summary
- Attendance progress and subject marks
- Weekly timetable and announcements
- Quick links and responsive mobile layout

## Files
`index.html`, `style.css`, `script.js`, `README.md`

## Run
Open `index.html` in a browser. The dashboard uses sample/demo academic data; replace it with verified information before presenting it as real.

## GitHub Pages
Create a repository such as `campus-pulse-dashboard`, upload these files to its root, then enable **Settings → Pages → Deploy from a branch → main → /(root)**.
